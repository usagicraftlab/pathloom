# Issue #21 — 任意スケッチ拘束・ソルバー拡張

## 目的と境界

指示021 / Issue #21は、平面スケッチを一つの履歴項目として保持し、要素内部に別の時系列履歴を作らずに拘束、寸法、ドラッグ、支持面、診断を扱う。既存のE系編集コマンドの意味は変更しない。C系65 commandの配置を一括でスケッチツールバーへ移す作業は既存契約・fixtureへの影響が大きいため本Issueの対象外とし、既存Rectangleから拘束付きスケッチへ入る経路と共通sketch model/solverを拡張する。

## 実装対象

- Point、Line、Circleと共有point IDを使うローカル平面モデル。任意の点・線・円を同じスケッチへ保持する。
- 一致、点-線上、水平、垂直、平行、直交、等長、同心、等半径、固定、距離、水平/垂直距離、線長、半径、直径、角度、軸対称。
- 駆動寸法と参照寸法。参照寸法は未知数を増やさず成功形状から測定する。
- hard/soft drag、完全拘束表示、自由度、冗長、矛盾候補、未収束、last-valid/draft保持。
- 拘束グラフの連結成分分離、変数/残差スケーリング、rank、成分別診断。
- sketch local origin、datum/face support、支持面移動時の自動追従、支持面消失時の最終位置保持と警告。
- Undo/Redo、通常Save/Openでsketch、support、last-valid、solve reportを保持する既存文書経路。

## 数値方針

- 現在解をwarm startとする減衰Gauss-Newtonを用いる。
- 線形stepは列pivot付きQRで解き、正規方程式の逆行列は作らない。
- 拘束グラフを連結成分へ分離し、各成分を独立に解く。一成分の失敗で無関係な成分を巻き戻さない。
- 位置と寸法を代表長で正規化するが、収束判定と製品診断の最大残差は元単位で評価する。
- 解析Jacobianを基本とし、対称等の複合拘束は中央差分で補う。

## 証拠

- unit: T03/T04/T05を維持し、P4-02として成分分離、遠方座標のスケーリング、hard drag、軸対称、参照寸法、支持面追従/消失を追加する。
- browser: 拘束Rectangleの完全拘束色、自由度、成分診断、矛盾時last-validを実Workerと通常Save/Open経路で確認する。
- 回帰: Node 24、Node 20.20.2、native全件、browser全件、GitHub CIを実行し、失敗・再実行・skip・未実行を区別して記録する。

## 既知の非対象

- Arc、Ellipse、NURBSの直接スケッチ編集と一般曲線接線拘束。
- C01〜C65の既存command UIを一括してスケッチ内ツールへ再配置すること。
- E系編集コマンドの意味・入力契約の変更。
- 実Mac GUI/Tauri/OS dialogの最終実機確認（Issue #37）。
